# Hariharan M — Professional Portfolio

A responsive, dependency-free static portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` directly or use VS Code Live Server.

## Deploy
### Vercel
Import the project folder/repository. Framework preset: **Other**. Build command: leave empty. Output directory: `.`.

### Netlify
Drag and drop this folder into Netlify, or connect the Git repository. No build command is required.

### GitHub Pages
Push the folder contents to a repository, then enable Pages from the repository's Settings → Pages. Select the branch and root folder.

## Structure
- `index.html` — home page
- `projects.html` — project details
- `assets/css/style.css` — responsive styling
- `assets/js/main.js` — mobile menu, reveal animations and year
- `assets/Hariharan_M_Resume.pdf` — resume linked from the site
- `404.html` — fallback page
- `robots.txt` — crawler access
